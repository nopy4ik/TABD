# TABD: TFT-анализ сети АЗС и Dash-дэшборд

Проект выполняет TFT-анализ сети АЗС по исходным данным задания. Цель: обучить модель временных рядов, сохранить веса и конфигурацию, построить интерактивный Dash-дэшборд с аналитикой, прогнозами, метриками модели и рекомендациями.

## Структура

- `_задание/` - исходные файлы задания. Эти данные не меняем.
- `notebooks/` - рабочие ноутбуки для EDA, обучения и отчета.
- `scripts/` - Python-скрипты подготовки, обучения, инференса и экспорта артефактов.
- `modeling/` - описание схемы TFT, признаков, метрик и артефактов модели.
- `app/` - Dash-приложение для интерактивного dashboard.
- `artifacts/` - результаты работы скриптов: веса модели, прогнозы, метрики, графики.
- `reports/` - ход лабораторной работы и текстовые материалы для отчета.

## Исходные данные

Основные файлы:

- `_задание/detailed_data.csv` - почасовые наблюдения по 25 АЗС за 2023 год.
- `_задание/stations_metadata.csv` - статические характеристики АЗС.
- `_задание/описание данных.docx` - описание переменных.
- `_задание/Задание.docx` - формулировка задания.
- `_задание/TFT_нализ.pdf` - статья/материал по TFT-анализу.

Важно: оригинальные CSV не редактируем. Например, `day_of_week` оставляем числом 0-6, потому что это корректный машинный признак. Человекочитаемые названия дней добавляются только в визуализациях Dash при необходимости.

## Запуск

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

Шаг 1. Сформировать прогнозы, метрики и рекомендации baseline:

```bash
python scripts/train_baseline.py
```

Шаг 2. Обучить или обновить TFT-прогноз топлива:

```bash
python scripts/train_tft.py
```

Можно продолжить обучение из сохраненного чекпоинта и задать число эпох:

```bash
python scripts/train_tft.py --epochs 12
```

Шаг 3. Запустить dashboard:

```bash
python app/app.py
```

Шаг 4. Открыть в браузере:

```text
http://127.0.0.1:8050/
```

## Порядок файлов

1. `scripts/train_baseline.py` читает `_задание/detailed_data.csv`, обучает модели, сохраняет артефакты в `artifacts/`.
2. `scripts/train_tft.py` обучает TFT для продаж топлива, сохраняет веса, backtest и будущий прогноз.
3. `app/app.py` читает исходные данные и файлы из `artifacts/`, затем строит интерактивный dashboard с переключением baseline/TFT.
4. `reports/lab_report.md` описывает ход лабораторной: что запускалось, зачем и какой результат получен.

## Важно про прогнозы

В dashboard разделены две разные вещи:

- проверка на декабре 2023 года: факт против прогноза, нужна для метрик;
- будущий прогноз после 2023-12-31: сценарный прогноз без фактических значений.
