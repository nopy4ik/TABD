## Принятое направление

- Дэшборды делаем на Python через Dash.
- Power BI больше не используем.
- Исходные файлы в `_задание/` не меняем.
- Производные артефакты сохраняем в `artifacts/`, а не рядом с исходниками.

## Текущее состояние

Dashboard можно проверять командой `python app/app.py`. В нем отдельно показаны:

- историческая проверка модели на декабре;
- будущий прогноз после 2023-12-31;
- метрики baseline и TFT;
- рекомендации по АЗС.

TFT обучена для `total_fuel_sales` на компактном 5-станционном наборе. Выручка магазина пока прогнозируется baseline-моделью.
